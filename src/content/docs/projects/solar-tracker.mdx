I didn't finish this, and I don't plan to. Showing my progress on it helped me get the Kratos internship.

The first version, in July 2022, crudely followed the light every 2 minutes. In August 2024 I restarted it to track smoothly. The restart got as far as a working sensor prototype, and the motors and housing never got built.

The prototype has two solar cells. Each one sits in its own voltage divider off a common supply, so an analog pin reads a relative brightness to compare between them. An Arduino reads the sensors, and a Raspberry Pi talks to it over serial at 9600 baud with three commands: `Find Sun`, `Reset`, and `Light`.

```cpp title="main/light_sensing.ino"
String getLightLevel(){
	double analogValue = analogRead(photoCellPin0);  // Read the analog value from the sensor
	int range = map(analogValue, sensorMin, sensorMax, 0, 4);  // Map sensor value to a range
	String lightLevel;

	switch (range) {
		case 0:
			lightLevel = "Dark: " + String((analogValue/ (float)sensorMax) * 100, 2) + "%";  // Dark 
			break;
		case 1:
			lightLevel = "Low: " + String((analogValue/ (float)sensorMax) * 100, 2) + "%";  // Low light
			break;
```

The sweep is sketched but empty. The plan stores a reading from each of 4 cells at each pitch and yaw, in 45 by 90 grids. The first version of that grid was too large for the Arduino. The commit history shows it was cut down to fit by lowering the angle precision. The next steps would have been choosing stepper or servo motors for pitch and yaw, designing a 3D-printed housing, and logging performance data.
