I started eeprep because people need help with their resumes. I built a system that worked, and eeprep is where I write it down.

eeprep covers projects to build, the one-page resume, and getting hired for an internship or a first full-time role. It also links to job boards and salary data. Its advice page says "The advice on these pages is one engineer's opinion." It takes no affiliate fees. It points to sources such as the Bureau of Labor Statistics, O\*NET, and NACE so a reader can check a claim.

It is a static site built with Astro and Starlight. Scripts check its wiki links, citations, external links, and mobile layout, and Vale checks the prose against a written style guide. The content is licensed CC BY 4.0 and the code is MIT.

This site shares its type, colors, and style guide.
